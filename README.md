# Jody Music

Frontend production-ready cho trung tâm âm nhạc tại Việt Nam, xây dựng với React 19, TypeScript, Vite, Tailwind CSS 4 và React Router.

## Khởi chạy

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Mock data nằm trong `src/data`; có thể thay bằng Spring Boot REST API mà không cần thay đổi interface của component.
